# Aprender

Aplicação Web de apoio ao processo de aprendizagem.

## Tecnologias

- React
- Vite
- JavaScript
- React Router
- CSS

## Objetivo

Auxiliar o usuário a:

entender → planejar → estudar → praticar → avaliar → acompanhar → continuar.
